# py-flappy-bird
CLI Flappy Bird game written in Python using curses

## How to Play
- Run `python3 flappy_bird.py`
- Press SPACE or UP arrow to make the bird flap
- Avoid the pipes
- Press P to pause/unpause
- Press Q to quit
- Press R to restart after game over

## Features
- Classic Flappy Bird gameplay
- Colorful terminal display
- Score tracking
- Pause functionality
- Game over and restart
