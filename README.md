# py-flappy-bird
CLI Flappy Bird game written in Python using curses

## How to Play
- Run `python3 py-flappybird.py ` for 1 player, or `python3 py-flappybird-2player.py` for 2 players
- Press SPACE or UP arrow to make the bird flap
  - For the 1 player file, either will control player 1's movement
  - For the 2 player file, UP will control player 1 (O), and SPACE arrow will control player 2 (X).
- Avoid the pipes
- Press Q to quit
